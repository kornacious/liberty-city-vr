# Vehicle editor third-party notices

The editor links the MIT-licensed librw fork (`LIBRW-LICENSE`), Dear ImGui
(`LICENSE_imgui.txt`) and ImGuizmo (`LICENSE_imguizmo.txt`), plus GLFW under the
zlib/libpng license (`GLFW-LICENSE.md`). These license files accompany installed
packages. The bundled stb_rect_pack, stb_textedit and stb_truetype headers retain
Sean Barrett and contributors' public-domain declarations in the source tree.
The generated glad OpenGL loader retains the Khronos platform permission notice
in `librw/src/gl/glad/khrplatform.h`.

Dear ImGui includes the ProggyClean font, copyright 2004, 2005 Tristan Grimmer,
under the MIT license (identified in `librw/skeleton/imgui/imgui_draw.cpp`).

Device operations use the adjacent Liberty City VR Manager and external Python 3
and ADB. See `manager/NOTICE.md` and `manager/ONIGWRAP-NOTICES.txt` for its NuGet
and native dependency inventory. CMake/CTest/CPack, C++17 and platform OpenGL/window
libraries are build/host dependencies. See the source kit's root NOTICE.md and
tools/README.md for the complete build-tool and optional authoring inventory.
